# 实施基线补充细则

仅在请求、所采用的 Plan 和已知事实仍需补充目标整理、修改定位或验证依据时，读取相关章节；已明确内容直接复用。共用范围、实施裁量、停止和验证规则由主 Skill 定义，本文件不建立第二套流程。

## 目标与约束提取

需要明确当前目标、预期行为、输入输出、In Scope / Out of Scope、关键约束与依赖、验收条件。
目标信息分散时，从当前请求及已采用材料提取目标、预期结果、明确限制和验收。保留必要来源，不因缺标题或字段重建已有设计。

## 最小修改范围定位

从请求或 Plan 点名对象出发，查找完成目标所需的直接修改点，复用已知事实；足以实施时停止扩展搜索。明确限制与预计落点的区分遵守主 Skill。

## 实施与验证依据核实

只补当前缺失的项目事实、接口信息或验证入口；生命周期、并发等按实际涉及程度查看。不能更改验收目标，但可以选择能证明该目标的适当检查方式。无法从事实确定的关键行为或严重冲突按主 Skill 停止与报告，不通过本引用补写新 Plan。
