# 评审报告模板

本文件定义完整评审报告的结构与字段；评审方法、事项语义和完成条件见 `review-guidelines.md`。

- 独立完整评审默认保留六章，局部核实和追问按当前目的简短表达。
- 前三章和共用字段沿用计划模板的含义。中文骨架是结构与 zh-CN 显示源；其他语言按主 Skill 的语言规则使用 terminology，不由本模板加载语言引用。
- 括号中的条件文字仅供实例化者判断，不写入最终报告；未命中条件时省略对应项，不留空占位。可选子节按实际顺序编号，Review 条目可按事项重复。
